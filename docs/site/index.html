codex-hot-media

Agent-friendly hot-list to original media planning CLI for Codex and Claude Code.

What It Means

codex-hot-media turns public and self-hosted hot-list signals into local planning artifacts: JSON reports, video plans, manual publish packs, CSV review logs, and dashboards. It keeps account login, upload, and final publishing manual.

Generate assets/image2/readme-hero.png with Image2 before claiming the Image2 project gate is complete.

Agent Paths

Codex

Claude Code

Uses CLAUDE.md and .claude/commands/hot-media.md.
