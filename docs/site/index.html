codex-hot-media

Agent-friendly hot-list to original media planning CLI for Codex and Claude Code.

What It Means

codex-hot-media turns public, self-hosted, manual, MCP, and optional AutoCLI hot-list signals into local planning artifacts: JSON reports, video plans, manual publish packs, CSV review logs, and dashboards. It keeps account login, upload, and final publishing manual.

Workflow

Agent Paths

Codex

Uses the repository skill and codex-hot-media --json agent-guide.

Claude Code

Uses CLAUDE.md and .claude/commands/hot-media.md.

Optional Bridges

NewsNow MCP and AutoCLI can feed inputs, while the CLI remains the normalization, planning, and safety layer.

Network Sources

Bilibili DailyHotApi RSSHub NewsNow TopHub Tech SoPilot TrendRadar OpenClaw AutoCLI Zhihu Weibo Xiaohongshu X/Twitter

AutoCLI Bridge

AutoCLI support is optional and source-level. Read and search profiles can flow into the same planning pipeline. Browser-session profiles require the user's own Chrome session through AutoCLI; write profiles are blocked unless explicit review enables them.

codex-hot-media --json autocli-profiles codex-hot-media --json collect --source autocli --autocli-profile zhihu-hot --limit 10 --out-dir outputs/data --prefix zhihu_hot codex-hot-media --json collect --source autocli --autocli-profile xiaohongshu-search --query AI --limit 10 --out-dir outputs/data --prefix xhs_ai
